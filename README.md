# Next.js starter

Next.js and TypeScript starter repository. The current homepage is the framework starter screen; social media features are not implemented.

[Website](https://social-media-tau-snowy.vercel.app)

## Project scope

The current home page is the default Next.js starter. There is no implemented social media feed or backend in this repository.

## Run locally

Install Node.js and the package manager used below. Run each command block from the repository root; separate frontend/backend processes use separate terminals.

Root application:

```sh
npm install
npm run dev
```

Other package scripts: `npm run build`, `npm run lint`.
